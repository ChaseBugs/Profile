4. С какими БД/кешем/брокерами работали (MSSQL/PostgreSQL, Redis, RabbitMQ/Kafka)?

Базы данных:
- Microsoft SQL Server (2019, 2022): основная БД, оптимизация запросов, индексы, хранимые процедуры
- PostgreSQL: для некоторых микросервисов, опыт с JSONB, полнотекстовый поиск
- MongoDB: для документоориентированных данных (логи, события)

Кэш:
- Redis: кэширование данных, сессии, rate limiting, pub/sub
- In-Memory Cache (.NET): для локального кэширования
- Distributed Cache (Redis): для распределенных систем

Брокеры сообщений:
- RabbitMQ: для асинхронной обработки задач, event-driven архитектура
- Apache Kafka: для event streaming, обработки больших объемов данных
- Azure Service Bus: в облачных проектах
